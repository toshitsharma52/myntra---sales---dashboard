# Myntra Sales Dashboard 📊

An interactive Excel dashboard project built using Myntra sales and product data to analyze brand performance, customer ratings, pricing trends, and category insights.

---

## 📌 Project Overview

This project focuses on cleaning, analyzing, and visualizing Myntra product sales data using Microsoft Excel. The dashboard helps identify:

* Top-performing brands
* Product pricing trends
* Customer rating distribution
* Sales insights by category
* High-demand products
* Brand-wise performance metrics

The project demonstrates skills in:

* Data Cleaning
* Data Analysis
* Pivot Tables
* Dashboard Design
* Data Visualization
* Excel Reporting

---

## 🛠️ Tools & Technologies Used

* **Microsoft Excel**

  * Pivot Tables
  * Pivot Charts
  * Slicers
  * Conditional Formatting
  * Data Cleaning Techniques

---

## 📂 Dataset Information

The dataset contains Myntra product-related information such as:

* Product Name
* Brand Name
* Ratings
* Rating Count
* Marked Price
* Discounted Price
* Sizes
* Categories

### Dataset Sheets

| Sheet Name          | Description                      |
| ------------------- | -------------------------------- |
| `unclean data`      | Raw dataset before preprocessing |
| `clean_data`        | Cleaned and processed data       |
| `question_1`        | Average marked price analysis    |
| `question_2`        | Brand-wise rating count analysis |
| `OVERALL_DASHBOARD` | Final interactive dashboard      |

---

## 📈 Dashboard Features

The dashboard provides:

* Brand-wise sales insights
* Average pricing analysis
* Rating performance tracking
* Interactive filters and slicers
* Comparative visual charts
* KPI summaries

---

## 🔍 Key Insights

Some insights generated from the dashboard include:

* Premium brands have higher average marked prices.
* Certain brands receive significantly higher customer engagement through ratings.
* Discount pricing strongly influences product popularity.
* Fashion categories show varying customer preferences.

---

## 🚀 How to Use

1. Download the Excel file.
2. Open in Microsoft Excel.
3. Navigate to the `OVERALL_DASHBOARD` sheet.
4. Use slicers and filters to explore insights interactively.
